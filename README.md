# FreshCuts Daily

Fresh chicken, mutton and seafood delivered to your doorstep across Bangalore apartment complexes.

**Live at:** https://freshcutsdaily.com

## About

FreshCuts Daily is a premium meat delivery platform serving 600+ customers across 25+ apartment complexes in Bangalore. Built and operated by Rizq Labs.

## Tech Stack

- **Frontend:** React + TypeScript + Vite
- **UI:** shadcn-ui + Tailwind CSS
- **Database:** Supabase (Postgres)
- **Deployment:** Vercel
- **Development:** GitHub Codespaces

## Local Development

```sh
# Clone the repository
git clone https://github.com/naveedam/freshcuts-direct-delight.git

# Navigate to project directory
cd freshcuts-direct-delight

# Install dependencies
npm install

# Start development server
npm run dev
```

## Deployment

Deployed automatically to Vercel on every push to `main`.

Custom domain: freshcutsdaily.com
